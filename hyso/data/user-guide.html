about.overview

HYSo nedir?

Bu nedir?

HYSo, PyTorch üzerinde görüntü sınıflandırma modelleri kurmak, eğitmek ve kayıtlı sonuçları incelemek için bir Python kütüphanesidir. Model görüntüyü sayısal çıktılara dönüştürür; eğitim, etiketli örneklerle ağırlıkları günceller.

Ne zaman kullanılır?

Model geliştirme ve kaynak maliyetini birlikte değerlendirmek istediğinizde kullanın.

Ne kazandırır?

Model kurma, ölçüm, karşılaştırma ve raporlama için birbirine bağlı yollar sağlar.

Sınırlar ve dikkat edilecekler

Bir model tanımı eğitim, analiz planı da yürütme değildir. Detection, segmentation ve her Graph birleşimi genel olarak desteklenmiş sayılmaz.

What is HYSo?

What is it?

HYSo is a Python library built on PyTorch for creating image-classification models, training them and examining saved results. A model maps images to numerical outputs; training updates its weights using labeled examples.

When to use it

Use it when you want to consider model development and resource costs together.

What you gain

It connects model construction, measurement, comparison and reporting workflows.

Limits and cautions

Defining a model does not train it; planning an analysis does not execute it. General detection, segmentation and arbitrary Graph combinations are not certified.

Was ist HYSo?

Was ist das?

HYSo ist eine Python-Bibliothek auf Basis von PyTorch. Sie unterstützt den Aufbau von Modellen zur Bildklassifikation, deren Training und die Auswertung gespeicherter Ergebnisse. Ein Modell berechnet Zahlen aus Bildern; beim Training werden seine Gewichte anhand beschrifteter Beispiele angepasst.

Wann ist es sinnvoll?

Nutzen Sie HYSo, wenn Sie Modellentwicklung und Ressourcenbedarf gemeinsam betrachten möchten.

Welchen Nutzen hat es?

Modellaufbau, Messung, Vergleich und Berichterstellung lassen sich miteinander verbinden.

Grenzen und Hinweise

Eine Modelldefinition startet kein Training; ein Analyseplan führt nichts aus. Allgemeine Objekterkennung, Segmentierung und beliebige Graph-Kombinationen sind nicht freigegeben.

¿Qué es HYSo?

¿Qué es?

HYSo es una biblioteca de Python basada en PyTorch para crear modelos de clasificación de imágenes, entrenarlos y examinar resultados guardados. El modelo transforma imágenes en salidas numéricas; el entrenamiento ajusta sus pesos con ejemplos etiquetados.

Cuándo utilizarlo

Utilícelo para estudiar el desarrollo del modelo junto con su coste en recursos.

Qué aporta

Conecta la construcción de modelos, las mediciones, las comparaciones y los informes.

Límites y precauciones

Definir un modelo no lo entrena y planificar un análisis no lo ejecuta. No se da por admitido el soporte general de detección, segmentación ni combinaciones arbitrarias de Graph.

Kurulum

Bu nedir?

Ayrı bir Python ortamı oluşturun ve HYSo wheel dosyasını bu ortama kurun. Python en az 3.10 olmalıdır. Torch ile torchvision birbiriyle uyumlu olmalıdır.

Ne zaman kullanılır?

Yeni bir proje veya temiz bir kurulum hazırlarken kullanın.

Ne kazandırır?

Proje bağımlılıklarını başka çalışmalarınızdan ayırırsınız. hyso-guide komutu rehberi Torch import etmeden bulur.

Sınırlar ve dikkat edilecekler

Normal kurulum eksik bağımlılıkları internetten isteyebilir. Çevrimdışı kurulumda bütün gerekli wheel dosyalarını önceden sağlayın; yalnız --no-deps kullanmak eksik bağımlılıkları kurmaz. Örnek yollar Windows içindir; POSIX sistemlerde .venv/bin/python ve .venv/bin/hyso-guide kullanın. Dosya yollarını kendi yerel dosyalarınıza uyarlayın.

Installation

What is it?

Create a separate Python environment and install the HYSo wheel there. Python must be at least 3.10. Torch and torchvision must be a compatible pair.

When to use it

Use a separate environment for a new project or a clean installation.

What you gain

Project dependencies stay separate from other work. The hyso-guide command locates this guide without importing Torch.

Limits and cautions

A normal installation may download missing dependencies. For offline installation, provide all required wheels in advance; --no-deps does not install missing dependencies. The example paths are for Windows; on POSIX use .venv/bin/python and .venv/bin/hyso-guide. Replace file paths with your own local files.

Installation

Was ist das?

Erstellen Sie eine eigene Python-Umgebung und installieren Sie dort das HYSo-Wheel. Erforderlich ist Python ab 3.10. Torch und torchvision müssen zueinander passen.

Wann ist es sinnvoll?

Eine eigene Umgebung empfiehlt sich für neue Projekte und saubere Installationen.

Welchen Nutzen hat es?

Abhängigkeiten bleiben von anderen Projekten getrennt. hyso-guide findet dieses Handbuch, ohne Torch zu importieren.

Grenzen und Hinweise

Fehlende Abhängigkeiten können bei der Installation Downloads auslösen. Für eine Offline-Installation müssen alle benötigten Wheels vorliegen; --no-deps ergänzt keine fehlenden Pakete. Die Beispielpfade gelten für Windows; unter POSIX verwenden Sie .venv/bin/python und .venv/bin/hyso-guide. Passen Sie die Dateipfade an Ihre lokalen Dateien an.

Cree un entorno de Python separado e instale en él el wheel de HYSo. Se requiere Python 3.10 o posterior. Torch y torchvision deben ser compatibles entre sí.

Así mantiene las dependencias aisladas de otros trabajos. hyso-guide encuentra esta guía sin importar Torch.

Bu nedir?

Önce sürümü ve bileşen listesini okuyun. CPU üzerinde küçük bir mimari tanımlayın; sonra eğitim verisini ve ayarlarını ayrı hazırlayın.

Ne kazandırır?

First steps

What is it?

Check the version and component list first. Define a small architecture on CPU, then prepare data and training settings separately.

When to use it

Follow this sequence when trying HYSo for the first time.

What you gain

It separates model construction, training preparation and actual training.

Limits and cautions

Builder.build() allocates fresh CPU weights. prepare_datasets() does not start training. Only an explicit fit() call trains; examples in this guide never run automatically.

Erste Schritte

Was ist das?

Prüfen Sie zuerst Version und Komponentenliste. Definieren Sie eine kleine CPU-Architektur und bereiten Sie anschließend Daten und Trainingseinstellungen getrennt vor.

Wann ist es sinnvoll?

Diese Reihenfolge eignet sich für den Einstieg.

Welchen Nutzen hat es?

Sie erkennen den Unterschied zwischen Modellaufbau, Trainingsvorbereitung und tatsächlichem Training.

Builder.build() legt neue CPU-Gewichte an. prepare_datasets() startet kein Training. Trainiert wird erst durch einen ausdrücklichen fit()-Aufruf; Beispiele in diesem Handbuch laufen nicht automatisch.

Primeros pasos

¿Qué es?

Compruebe primero la versión y la lista de componentes. Defina una arquitectura pequeña en CPU y prepare por separado los datos y los ajustes de entrenamiento.

models.support

Desteklenen model yolları

Bu nedir?

ModularCNN, yapı taşlarından kurulan sequential modeller ve Graph modelleri ana kurulum yollarıdır. ModularCNN, genişliği, blok tekrarları ve stride değerleri ayarlanabilen residual aşamalardan oluşur; attention seçimi mevcut profilin sınırları içindedir. Sınıflandırmada çıktı genellikle her sınıf için bir skordur; bu skorlar doğrudan olasılık değildir.

Ne zaman kullanılır?

Önce veri girişini, sınıf sayısını ve kurulum profilini seçerken kullanın.

Ne kazandırır?

Hangi API ve bileşenin kurulumunuzda bulunduğunu ModelRegistry.list() veya hyso models list ile görebilirsiniz.

Sınırlar ve dikkat edilecekler

Geliştirme checkout’u ile commercial wheel aynı mimari listesini sunmaz. Bu listedeki bir sınıfın varlığı eğitim, resume veya GPU için bütün birleşimlerin kabulü değildir.

Supported model paths

What is it?

ModularCNN, sequential models built from components and Graph models are the main construction paths. ModularCNN assembles residual stages with configurable widths, block repetitions and strides; attention choices remain within the existing profile. Classification outputs are usually scores for each class, not probabilities by themselves.

When to use it

Start here when choosing input shape, class count and installation profile.

What you gain

ModelRegistry.list() or hyso models list shows what your installation provides.

Limits and cautions

The development checkout and commercial wheel expose different architecture sets. The presence of a class does not certify every training, resume or GPU combination.

Unterstützte Modellwege

Was ist das?

Die wichtigsten Wege sind ModularCNN, aus Komponenten aufgebaute sequenzielle Modelle und Graph-Modelle. ModularCNN besteht aus Residualstufen mit einstellbarer Breite, Blockanzahl und Schrittweite; die Attention-Auswahl bleibt auf das vorhandene Profil begrenzt. Klassifikationsausgaben sind meist Klassenwerte und für sich genommen keine Wahrscheinlichkeiten.

Wann ist es sinnvoll?

Beginnen Sie hier, wenn Sie Eingabeform, Klassenzahl und Installationsprofil festlegen.

Welchen Nutzen hat es?

ModelRegistry.list() oder hyso models list zeigt die Komponenten Ihrer Installation.

Grenzen und Hinweise

Entwicklungs-Checkout und commercial Wheel enthalten unterschiedliche Architekturen. Eine vorhandene Klasse bedeutet keine Freigabe sämtlicher Trainings-, Resume- oder GPU-Kombinationen.

Modelos disponibles

¿Qué es?

Las vías principales son ModularCNN, los modelos secuenciales construidos con componentes y los modelos Graph. ModularCNN reúne etapas residuales con anchura, repeticiones y stride configurables; la selección de attention se limita al perfil existente. En clasificación, las salidas suelen ser puntuaciones por clase, no probabilidades por sí solas.

Cuándo utilizarlo

Empiece aquí al elegir la forma de entrada, el número de clases y el perfil instalado.

Qué aporta

ModelRegistry.list() o hyso models list muestra los componentes disponibles en su instalación.

Límites y precauciones

El checkout de desarrollo y el wheel commercial ofrecen conjuntos distintos. Que exista una clase no certifica todas las combinaciones de entrenamiento, reanudación o GPU.

models.legacy

Eski model ve yardımcı API’ler

Bu nedir?

ELO ve CEMO mevcut CNN sınıflarıdır. CNNSENormalWithFit eski eğitim kolaylıklarını taşır. EBO, ELO modelini saran eski eğitim arayüzüdür. EMA ise ağırlıkların yumuşatılmış kopyasını tutan yardımcıdır; bunların hepsi ayrı tam model aileleri değildir.

Ne zaman kullanılır?

Eski projelerin import ve state düzenini korumak gerektiğinde kullanın.

Ne kazandırır?

Yeni projeleri Builder ve Trainer ile kurarken eski projeleri aynı anda sürdürebilirsiniz.

Sınırlar ve dikkat edilecekler

Eski sınıflar kanonik ResNet veya DenseNet diye yeniden adlandırılmaz. Wildcard import sırası korunur; yeni bileşenleri açık adlarıyla import edin. EBO cihazı belirtilmezse CUDA'yı otomatik seçebilir; CPU kullanımı için device='cpu' değerini açıkça verin.

Legacy models and helpers

What is it?

ELO and CEMO are existing CNN classes. CNNSENormalWithFit retains older training conveniences. EBO is a legacy training wrapper around ELO, and EMA maintains a smoothed copy of weights; these names do not all denote complete model families.

When to use it

Use these interfaces when maintaining older imports and state layouts.

What you gain

Older projects can remain intact while new ones use Builder and Trainer.

Limits and cautions

Legacy classes are not relabeled as canonical ResNet or DenseNet. Wildcard import order is retained; import newer components by their explicit names. If no device is given, EBO may choose CUDA automatically; explicitly set device='cpu' for CPU use.

Ältere Modelle und Hilfs-APIs

Was ist das?

ELO und CEMO sind bestehende CNN-Klassen. CNNSENormalWithFit enthält ältere Trainingshilfen. EBO ist eine ältere Trainingsschnittstelle um ELO; EMA verwaltet eine geglättete Gewichtskopie. Nicht jeder dieser Namen bezeichnet eine vollständige Modellfamilie.

Wann ist es sinnvoll?

Diese Schnittstellen dienen der Pflege älterer Imports und Zustandsstrukturen.

Welchen Nutzen hat es?

Bestehende Projekte bleiben nutzbar, während neue Projekte Builder und Trainer verwenden.

Grenzen und Hinweise

Convolution: görüntüde desen arama

Bu nedir?

Convolution, küçük bir öğrenilebilir filtreyi görüntü üzerinde gezdirir. conv2d genel işlemdir; pointwise_conv2d kanalları 1×1 filtreyle karıştırır. Depthwise her kanalı ayrı işler; separable türler bu işleri ayırır. ConvNormAct convolution, normalization ve activation’ı birleştirir.

Ne zaman kullanılır?

Kenar, doku ve daha sonra daha karmaşık özellikler öğrenmek için kullanın.

Ne kazandırır?

Kanal sayısı, kernel ve stride ile model kapasitesi ve çıktı boyutunu açıkça seçersiniz.

Sınırlar ve dikkat edilecekler

Giriş kanalları önceki çıktıyla eşleşmeli, groups kanalları bölmelidir. Stride örneklemeyi seyrekleştirir; dilation filtre aralığını değiştirir. Daha az işlem her cihazda daha hızlı çalışma demek değildir. conv_transpose2d tek başına bir convolution’ın tam tersi değildir.

Convolution: finding image patterns

What is it?

A convolution moves a small learned filter across an image. conv2d is the general operation; pointwise_conv2d mixes channels with a 1×1 filter. Depthwise works on channels separately, while separable variants split the work. ConvNormAct combines convolution, normalization and activation.

When to use it

Use these layers to learn edges, textures and progressively richer features.

What you gain

Channels, kernel and stride give explicit control over capacity and output shape.

Limits and cautions

Input channels must match the preceding output, and groups must divide the channels. Stride reduces sampling density; dilation spaces filter taps apart. Fewer operations do not guarantee a faster device runtime. conv_transpose2d is not an exact inverse convolution.

Faltung: Bildmuster erkennen

Was ist das?

Eine Faltung verschiebt einen kleinen lernbaren Filter über das Bild. conv2d ist die allgemeine Operation; pointwise_conv2d mischt Kanäle mit einem 1×1-Filter. Depthwise verarbeitet Kanäle einzeln, separierbare Varianten teilen die Arbeit auf. ConvNormAct verbindet Faltung, Normalisierung und Aktivierung.

Wann ist es sinnvoll?

Damit lernt ein Modell Kanten, Texturen und zunehmend komplexe Merkmale.

Welchen Nutzen hat es?

Kanäle, Kernel und Schrittweite steuern Kapazität und Ausgabeform ausdrücklich.

Grenzen und Hinweise

Eingangskanäle müssen zur vorherigen Ausgabe passen; groups muss die Kanalzahlen teilen. Stride verringert die Abtastdichte, Dilation vergrößert die Filterabstände. Weniger Rechenoperationen garantieren keine kürzere Laufzeit. conv_transpose2d ist keine exakte Umkehrung einer Faltung.

Convolución: detectar patrones en imágenes

¿Qué es?

Una convolución desplaza un pequeño filtro aprendido por la imagen. conv2d es la operación general; pointwise_conv2d mezcla canales con un filtro 1×1. Depthwise procesa cada canal por separado y las variantes separables dividen el trabajo. ConvNormAct combina convolución, normalización y activación.

Cuándo utilizarlo

Utilice estas capas para aprender bordes, texturas y características cada vez más complejas.

Qué aporta

Los canales, el kernel y el stride permiten controlar la capacidad y la forma de salida.

Límites y precauciones

Los canales de entrada deben coincidir con la salida anterior y groups debe dividir los canales. Stride reduce la densidad de muestreo y dilation separa las posiciones del filtro. Menos operaciones no garantizan menor tiempo de ejecución. conv_transpose2d no es una inversión exacta de una convolución.

What is it?

When to use it

Use it to control the scale of intermediate values during training.

Normalisierung: Wertebereiche regulieren

Was ist das?

Sie hilft, die Größenordnung von Zwischenwerten beim Training zu regulieren.

Activation: doğrusal olmayan dönüşüm

Bu nedir?

Activation, katman çıktısını dönüştürerek modelin basit doğrusal ilişkilerden fazlasını öğrenmesini sağlar. ReLU negatifleri sıfırlar; LeakyReLU negatif tarafta küçük eğim bırakır. PReLU bu eğimi öğrenir; SiLU, GELU ve Mish daha yumuşak dönüşümlerdir. HardSwish/HardSigmoid parçalı yaklaşımlardır.

Ne zaman kullanılır?

Özellik çıkaran katmanlar arasında kullanın.

Ne kazandırır?

Model daha karmaşık ilişkiler kurabilir.

Activation: a nonlinear transformation

What is it?

An activation transforms a layer output so the model can learn more than linear relationships. ReLU clips negative values; LeakyReLU keeps a small negative slope. PReLU learns that slope; SiLU, GELU and Mish are smoother transformations. HardSwish/HardSigmoid use piecewise approximations.

When to use it

Place activations between feature-extraction layers.

What you gain

They let a model represent more complex relationships.

Limits and cautions

Activations differ in range and computational cost. identity leaves values unchanged. Do not add an extra softmax to classification logits without checking the loss contract.

Aktivierung: nichtlineare Umformung

Was ist das?

Eine Aktivierung verändert die Schichtausgabe, damit das Modell mehr als lineare Beziehungen lernen kann. ReLU setzt negative Werte auf null; LeakyReLU behält dort eine kleine Steigung. PReLU lernt diese Steigung. SiLU, GELU und Mish sind glattere Umformungen; HardSwish/HardSigmoid verwenden abschnittsweise Näherungen.

Wann ist es sinnvoll?

Aktivierungen werden zwischen merkmalsextrahierenden Schichten eingesetzt.

Welchen Nutzen hat es?

Das Modell kann komplexere Zusammenhänge darstellen.

Grenzen und Hinweise

Wertebereich und Rechenaufwand unterscheiden sich. identity verändert nichts. Ergänzen Sie Klassifikations-Logits nicht ungeprüft um softmax; entscheidend ist der Vertrag der Verlustfunktion.

Activación: una transformación no lineal

¿Qué es?

Una activación transforma la salida de una capa para aprender relaciones no lineales. ReLU anula los valores negativos; LeakyReLU conserva una pequeña pendiente negativa. PReLU aprende esa pendiente. SiLU, GELU y Mish son transformaciones más suaves; HardSwish/HardSigmoid usan aproximaciones por tramos.

Cuándo utilizarlo

Se colocan entre capas que extraen características.

Qué aporta

Permiten representar relaciones más complejas.

Límites y precauciones

Las activaciones difieren en rango y coste. identity no modifica los valores. No añada softmax a los logits de clasificación sin comprobar el contrato de la función de pérdida.

Bu nedir?

Pooling: reducing feature-map size

What is it?

Pooling summarizes nearby values. Max pooling keeps the largest; average pooling takes the mean. Adaptive pooling lets you request an output size; global average pooling reduces each channel to one value.

When to use it

Use it to reduce spatial size and the cost of later layers.

What you gain

It can connect varying image sizes to a more regular prediction head.

Limits and cautions

Downsampling loses detail. Kernel, stride and padding must produce valid outputs. Pooling operates within channels and does not learn the class decision by itself.

Pooling: Merkmalskarten verkleinern

Was ist das?

Pooling fasst benachbarte Werte zusammen. Max-Pooling übernimmt den größten Wert, Average-Pooling den Mittelwert. Adaptives Pooling erlaubt eine feste Ausgabegröße; Global Average Pooling reduziert jeden Kanal auf einen Wert.

Wann ist es sinnvoll?

Es verkleinert räumliche Abmessungen und den Aufwand nachfolgender Schichten.

Welchen Nutzen hat es?

Unterschiedliche Bildgrößen lassen sich an einen einheitlicheren Vorhersagekopf anbinden.

Grenzen und Hinweise

Die Verkleinerung verliert Details. Kernel, Schrittweite und Padding müssen gültige Ausgaben erzeugen. Pooling arbeitet innerhalb der Kanäle und lernt allein keine Klassenentscheidung.

Pooling: reducir los mapas de características

¿Qué es?

Pooling resume valores próximos. Max pooling conserva el máximo y average pooling calcula la media. Adaptive pooling permite elegir el tamaño de salida; global average pooling reduce cada canal a un valor.

Cuándo utilizarlo

Úselo para reducir el tamaño espacial y el coste de las capas posteriores.

Qué aporta

Ayuda a conectar imágenes de distintos tamaños con una cabeza de predicción más uniforme.

Límites y precauciones

La reducción pierde detalles. Kernel, stride y padding deben producir salidas válidas. Pooling actúa dentro de los canales y no aprende por sí solo la decisión de clase.

What is it?

Use them to connect shapes explicitly or change resolution.

What you gain

Shape changes become visible instead of hidden conversions.

Limits and cautions

reshape must preserve element count; shuffle variants require divisibility. resize cannot recover lost detail, and bicubic can exceed the input value range. channel_shuffle reorders channels and does not learn features by itself.

Trainer: the learning loop

What is it?

Trainer manages forward passes, loss computation, backpropagation and optimizer updates. Loss expresses training error relative to targets; gradients help determine how weights should change.

What is it?

A checkpoint is a saved snapshot of training state. Resume continues from a completed point with a matching model, data, optimizer and total epoch budget. Architecture JSON alone is not a checkpoint.

When to use it

Use it to continue longer training or restore a supported model state.

What you gain

It restores supported training state consistently, rather than only weights.

Reading metrics

What is it?

Time uses ms/s, throughput images/s, memory bytes and energy J/image. P50 is the median; P95/P99 summarize the slower tail. Accuracy is the share of correct predictions; precision concerns the correctness of positive predictions and recall the recovery of actual positives.

When to use it

What you gain

You can distinguish quantities that look similar but use different denominators.

Limits and cautions

A fraction of 0.92 equals 92%; moving from 90% to 92% is 2 percentage points. Trainer history may use accuracy percentages while P26 uses fractions; the recorded unit is authoritative. Tail percentiles may be unreliable with few samples. High throughput alone proves neither low latency nor high quality.

The Model Analyzer workflow

What is it?

Analysis combines questions about a model with available evidence. plan_analysis selects features, preflight_analysis checks prerequisites, and execute_analysis runs only explicitly authorized operations. UnifiedAnalysisReport organizes retained records.

When to use it

Use it to see which measurements are available and which are missing.

What you gain

Plan without mistaking missing inputs for measurements, and revisit saved results without retraining. A receipt is a producer verification record linking an observation to its source and protocol; it carries evidence only for its declared scope.

Limits and cautions

ModelContext fields are caller declarations, not verified device or checkpoint identities. The Analyzer does not repair model code or invent missing results. Sources, protocols, resource limits and permissions are checked separately at execution.

Der Model-Analyzer-Ablauf

Was ist das?

Eine Analyse verbindet Fragen zum Modell mit vorhandenen Nachweisen. plan_analysis wählt Merkmale aus, preflight_analysis prüft Voraussetzungen und execute_analysis führt nur ausdrücklich autorisierte Operationen aus. UnifiedAnalysisReport ordnet gespeicherte Aufzeichnungen.

Wann ist es sinnvoll?

Damit sehen Sie, welche Messungen vorhanden sind und welche fehlen.

Welchen Nutzen hat es?

Sie planen, ohne fehlende Eingaben mit Messungen zu verwechseln, und prüfen gespeicherte Ergebnisse ohne erneutes Training. Ein Receipt ist ein Prüfvermerk des Erzeugers, der Beobachtung, Quelle und Protokoll verknüpft; es belegt nur seinen ausdrücklich angegebenen Bereich.

Grenzen und Hinweise

ModelContext-Felder sind Nutzerangaben, keine verifizierten Geräte- oder Checkpoint-Identitäten. Der Analyzer repariert keinen Modellcode und erfindet keine Ergebnisse. Quellen, Protokolle, Ressourcengrenzen und Berechtigungen werden bei der Ausführung gesondert geprüft.

¿Qué es?

Úselo para saber qué mediciones están disponibles y cuáles faltan.

Límites y precauciones
