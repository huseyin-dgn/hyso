# P0.6-C1 — OneCycleLR Cross-Version Checkpoint Fix

## 1. Başlangıç ve kök neden

Branch `feature/hyso-training-core`, HEAD `da543ae8f2f9d787e0547848d7e9699bb1a08b92`;
başlangıç çalışma ağacı temizdi. P0.6-C'nin mevcut temiz Python 3.10.18 /
Torch 2.2.2+cpu / torchvision 0.17.2+cpu / NumPy 1.26.4 ortamında hata düzeltmeden
önce tekrar üretildi: `scheduler.anneal_func: unsupported value type builtins.function`.

Torch 2.2.2 OneCycleLR.state_dict, cosine/linear annealing için `anneal_func`
fonksiyonunu içerir. Torch 2.5.1+cu121 bunun yerine `_anneal_func_type='cos'/'linear'`
plain string kullanır. Diğer state alanları bu gerçek iki runtime'da eşleşir.
Kurulu gerçek PyTorch kaynakları inspect ile karşılaştırıldı: eski get_lr doğrudan
anneal_func çağırır; yenisi string'e göre kendi statik fonksiyonunu seçer.

Üç ayrı etki: `_safe` kayıt anında callable'ı reddediyordu; EBO planının JSON
normalizasyonu aynı callable ile başarısızdı; string state'i eski scheduler'a
doğrudan yüklemek ise kullanılan gerçek anneal_func davranışını geri getirmeye yetmezdi.
Özellikle farklı stratejiyle oluşturulan target'ta yanlış annealing riski vardı.

## 2. State farkı ve normalizasyon

| Katman | Torch 2.2.2 | Torch 2.5.1 |
|---|---|---|
| Native state | anneal_func = bilinen statik fonksiyon | _anneal_func_type = cos/linear |
| Dosya / EBO planı | _anneal_func_type = cos/linear | Mevcut plain temsil aynen |
| Native restore | Caller scheduler'a güvenilir yerel fonksiyon geri kurulur | String state yüklenir |

`hyso/checkpoint.py` yalnız exact PyTorch OneCycleLR tipini ve bilinen state
alanlarını kabul eder. Eski callable, import sırasında referansı alınan gerçek
PyTorch statik fonksiyonlarıyla **object identity** üzerinden eşleştirilir;
isim/qualname benzerliği yeterli değildir. Unknown callable, subclass, çelişen
iki temsil, bilinmeyen/eksik alan ve bilinmeyen/non-string strateji reddedilir.

Fonksiyon yalnız runtime'da caller-created eski scheduler için yeniden kurulur;
checkpoint'e yazılmaz, dosyadan import/execute edilmez. State alanları sessizce
atılmadı: total_steps, phases, base_lrs, momentum/beta seçimi, sayaçlar ve diğer
bilinen alanlar korunur. Genel scheduler scalar/type/field doğrulaması sürer.
OneCycle dışındaki component/save/load davranışı değiştirilmedi.
