yayımlanmış bir release değildir. PyPI/TestPyPI/GitHub Release/tag işlemi yapılmadı.

## 2. Metadata ve seçilen destek politikası

| Alan | Önce | Candidate |
|---|---|---|
| Version | 0.1.6 | **0.2.0** |
| Requires-Python | >=3.8 | **>=3.10** |
| torch | >=2.0 | **>=2.2.2** |
| torchvision | >=0.14 | **>=0.17.2** |

Canonical metadata `setup.cfg` içinde. `pyproject.toml` yalnız setuptools build
backend'ini tanımlıyor; ikinci bir version/dependency kaydı eklenmedi, dosya korunuyor.
Python 3 classifier'ı korunup Python 3 Only eklendi; test edilmemiş bütün Python
minor sürümleri için ayrı classifier eklenmedi. NumPy, matplotlib, seaborn,
scikit-learn, tqdm ve torchsummary gereksinimleri korundu; yeni dependency veya
global NumPy<2 sınırı eklenmedi.

Bu alt sınırlar **destek politikasıdır**, bütün >= kombinasyonlarının runtime
PASS olduğu iddiası değildir. Alt profil exact Windows x64/Python 3.10.18/
Torch 2.2.2+cpu/vision 0.17.2+cpu/NumPy 1.26.4'tür. 3.10'ın daha eski patch'leri,
diğer Python minor sürümleri ve diğer Torch/vision kombinasyonları ayrıca doğrulanmadı.
Python 3.8/3.9 ve Torch 1.x/2.0/2.1 kullanıcıları 0.2.0 için runtime yükseltmeli
veya uygun eski HYSo sürümünde kalmalı; geniş tarihsel destek garantisi verilmez.

Torch/vision eşleri ve binary kanalları birlikte seçilmeli: 2.2.2/0.17.2 CPU ve
2.5.1/0.20.1 cu121 doğrulanmış profillerdir. Eski Torch profili için exact
NumPy 1.26.4 yeniden üretim constraint'idir; eski binary/NumPy 2 ABI riski sürer.
Yeni referans NumPy 2.2.2 kullandığından global NumPy<2 gereği çıkarılmadı.

## 3. README, release notes ve kaynak sınırları

README ve `docs/release-notes/0.2.0-draft.md` yeni minimumları, yerel 0.2.0 kimliğini
ve henüz yayımlanmamış candidate durumunu açıklıyor. Eski 0.1.6 atıfları yalnız
yayımlanmış önceki sürüm/compatibility bağlamında bırakıldı.

Belgeler model-only raw state_dict ile full-state v1 ayrımını; EBO'nun
`save_last_to`/`resume_from` API'sini, özgün toplam epoch bütçesini, ImageFolder/Subset
ve loader/transform sınırlarını koruyor. Path/size/mtime fingerprint içerik bütünlüğü
garantisi değildir; mid-epoch, multi-worker, custom/stateful callback ve multi-GPU
resume desteklenmez. CEMO/CNNS fit'e EBO resume API'si eklenmedi.

OneCycleLR'nin Torch 2.2.2 legacy callable ve 2.5.1 plain strategy uyumluluğu
release notes'a eklendi. Format v1 ve weights_only=True korunur; bilinmeyen scheduler
şemaları için genel uyum garantisi yok. Üretim `hyso/` dosyaları değişmedi;
EBO.fit imzası, training algoritması ve model state_dict şeması aynı.
