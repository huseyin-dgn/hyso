## 4. Torch alt sınırı ve Python/torchvision

Mevcut EBO.fit OneCycle yolunda `self.optimizer.register_step_post_hook(...)` çağrısı kullanıyor (`hyso/models/bcam.py:413`). Tam fit seçeneklerini destekleme beyanı bu API'yi gerektiriyor.

[PyTorch v1.13.1 optimizer kaynağında](https://github.com/pytorch/pytorch/blob/v1.13.1/torch/optim/optimizer.py) bu metot yok; [v2.0.0 kaynağında](https://github.com/pytorch/pytorch/blob/v2.0.0/torch/optim/optimizer.py) var. Dolayısıyla P0.3-A'nın **torch>=2.0** beyanı korundu; eski sürümü desteklemek için eğitim/scheduler kodu değiştirilmedi.

Bu, yayımlanmış torch>=1.13 beyanına göre **bilinçli destek daralmasıdır**; eski Torch ortamlarıyla geriye uyumlu release olarak sunulamaz.

[torch 2.0.0 resmî metadata](https://pypi.org/pypi/torch/2.0.0/json) Requires-Python>=3.8.0; [torchvision 0.15.1](https://pypi.org/pypi/torchvision/0.15.1/json) Requires-Python>=3.8 ve torch==2.0.0 tanımlıyor. Python>=3.8 için metadata bakımından uyumlu bir eşleşme vardır.

Mevcut torchvision>=0.14 alt sınırı daha gevşektir; [0.14.1'in torch==1.13.1 bağımlılığı](https://pypi.org/pypi/torchvision/0.14.1/json) HYSo torch>=2.0 koşuluyla uyuşmadığı için resolver bu adayı kabul etmemelidir. Daha yeni uyumlu aday seçilmesini engelleyen bir üst sınır yok; gereksiz metadata değişikliği yapılmadı.

Bu tespitler minimum sürümlerde runtime başarısını kanıtlamaz. Gerçek test ortamı Python 3.10.18 / torch 2.5.1+cu121 / torchvision 0.20.1+cu121'dir. Python 3.8, Torch 2.0 ve gerçek CUDA matrisi çalıştırılmadı; bunlar çalıştırılmış destek olarak ilan edilmez.
