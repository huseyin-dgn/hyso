## 1. Eski model-only format

`ModelCheckpoint` aynı API ve davranışla yalnızca `model.state_dict()` kaydediyor; best-loss koşulu korunuyor. Bu ham .pth dosyaları full-state formatı olarak yorumlanmıyor. Callback, model mimarileri ve mevcut state_dict/checkpoint şemaları değiştirilmedi.

## 2. Yeni format

Yeni canonical modül: `hyso.checkpoint`. Version 1 payload:

| Alan | İçerik |
|---|---|
| format / format_version | "hyso.training" / 1 |
| model | Tip adı ve state_dict |
| optimizer | Tip, state_dict, grup sırasıyla model parameter isimleri; yoksa None |
| scheduler / scaler | Tip ve state_dict; yoksa None |
| ema | EMA/shadow tipleri, shadow state_dict ve decay; yoksa None |
| completed_epochs | Negatif olmayan Python int |
| history / metrics | Plain dict veya None |
| rng_state | İsteğe bağlı Python, NumPy, CPU torch ve zaten initialize edilmiş CUDA RNG; yoksa None |

Nesneler veya class implementasyonları kaydedilmiyor; tip adları yalnızca doğrulama için string. Veriler tensor ve izin verilen plain scalar/container türleriyle sınırlı. State_dict OrderedDict metadata'sı korunuyor. Kapalı scaler'ın gerçek boş state_dict'i **{}**, bulunmayan scaler ise **None**; birbirine karıştırılmıyor.

## 3. Save/load sözleşmesi

`save_training_checkpoint(path, model, *, optimizer=None, scheduler=None, scaler=None, ema=None, completed_epochs=0, history=None, metrics=None, include_rng=False)`

`load_training_checkpoint(path, model, *, optimizer=None, scheduler=None, scaler=None, ema=None, map_location="cpu", restore_rng=False)`

Caller model/optimizer/scheduler/scaler/EMA nesnelerini önceden oluşturur. Scheduler callback wrapper'ı yerine gerçek scheduler verilir; scheduler aynı optimizer'a bağlı olmalıdır. Scheduler dahil bütün nesneler load öncesinde oluşturulmalıdır. Save/load otomatik model/optimizer üretmez.

Load; epoch/history/metrics, RNG verisi ve rng_restored bilgisini döndürür. Dosyada bulunan bir training bileşeni hedefte eksikse veya checkpoint'te bulunmayan bileşen hedef olarak verilirse açık hata oluşur; state sessizce atılmaz. Model tensor key/shape/dtype, component tipi ve optimizer parameter grup/sırası doğrulanır. Tip/şema migration'ı yapılmaz.

Caller kayıt anını tamamlanmış optimizer/epoch sınırında seçmelidir; completed_epochs/history tutarlılığı kendiliğinden hesaplanmaz.

## 4. Doğrulanan bileşenler

Gerçek CPU nn.Sequential + Linear/BatchNorm model; **Adam, AdamW ve momentum SGD × StepLR/OneCycleLR** altı kombinasyonda sınandı. Her kaynak optimizer iki gerçek adım attı; target bağımsız oluşturuldu. Model parametre/buffer'ları, optimizer moment/momentum state'i, scheduler state/sayaçları, EMA shadow/decay ve metadata sıfır toleransla karşılaştırıldı.

Yükleme sonrasında bir sonraki **manuel** optimizer/scheduler adımı da kaynakla aynı sonucu verdi. Bu, component round-trip kontrolüdür; fit resume veya tam eğitim tekrar üretilebilirliği kanıtı değildir.

## 7. Güvenlik ve format kontrolü

Tek okuma yolu `torch.load(..., weights_only=True, map_location=...)`; **unsafe fallback veya allowlist genişletmesi yok**. Format magic/version ve gerekli alanlar doğrulanıyor; legacy/unknown dosya açıklayıcı TrainingCheckpointError ile reddediliyor. Kullanıcı class/global nesneleri state verisine kabul edilmiyor. Bu, keyfi dosyaya karşı kaynak tüketimi/authenticity garantisi değildir.

Save, hedefle aynı dizinde benzersiz temporary dosyaya torch.save + flush/fsync yapar; başarıdan sonra os.replace kullanır. Hata olursa temp temizlenir ve mevcut hedef korunur. Parent dizin otomatik oluşturulmaz. Farklı filesystem/crash senaryolarında dayanıklılık veya eşzamanlı writer koordinasyonu sınanmadı.

Load uygulaması başarısız olursa component state snapshot'larına geri dönmeyi dener; rollback de başarısızsa hedeflerin kısmen yüklenmiş olabileceğini açıkça bildirir. Custom load hook yan etkileri için genel transaction garantisi verilmez.
