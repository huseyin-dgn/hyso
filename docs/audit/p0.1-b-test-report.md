EBO ileriye dönük test işareti:

```python
@pytest.mark.xfail(
    strict=True, reason="R01: EBO forward is missing", raises=NotImplementedError,
)
```

`raises` kısıtı nedeniyle farklı exception türleri ve assertion hataları otomatik expected failure sayılmaz. Beklenmedik gerçek geçiş XPASS(strict) ile suite'i başarısız yapar. Hata ileride giderilirse bugünkü characterization beklentisi de açıkça güncellenmelidir; testler bunu sessizce benimsemez.

Bu testler optimizer adımı veya eğitim döngüsü doğruluğu ölçümü değildir.

- R01 üretim hatası korunuyor ve görünür strict XFAIL. Tarihsel checkpoint yokluğu nedeniyle tarihsel uyumluluk iddiası yok.
- Paket build/kurulum ve P0.1-C training correctness bu görev kapsamında çalıştırılmadı.
