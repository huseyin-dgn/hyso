## 6. Training ve checkpoint doğrulama matrisi

| Özellik | Kanıt / sınır |
|---|---|
| Optimizer | CPU gerçek SGD/Adam/AdamW; GPU Adam/AdamW. Custom optimizer resume yok |

| AMP / GradScaler | CPU disabled ve CPU overflow regression; GPU aktif FP16, gerçek inf overflow/skip/backoff |
| EMA | Parametre formülü ve BatchNorm float/integer buffer tam kopyası; CPU/GPU round-trip ve resume |

| EBO TensorDataset resume | CPU 8 optimizer/scheduler/EMA kombinasyonu; GPU 4 optimizer/scheduler kombinasyonu, RNG/history eşliği |
| ImageFolder / Subset resume | CPU deterministik/rastgele transform matrisi; GPU 4 pozitif + 6 negatif senaryo |
