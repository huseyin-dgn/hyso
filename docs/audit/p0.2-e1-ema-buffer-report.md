Yeni buffer-only model testi float64, int64, bool ve non-persistent cache'i iki update boyunca tam eşitlikle kontrol eder. Shadow storage adresleri sabit, kaynak storage'ından farklıdır; sonraki canlı değişim shadow'u kendiliğinden değiştirmez. Cache kopyalanır ancak state_dict dışında kalır.
