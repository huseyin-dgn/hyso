**Yeni doğrulanmış release blocker:** Torch 2.2.2 OneCycleLR.state_dict() içinde
`anneal_func` bir Python fonksiyonudur. `hyso/checkpoint.py:49` bunu güvenli plain
state sözleşmesine göre reddeder:

`scheduler.anneal_func: unsupported value type builtins.function`

Ayrı gerçek EBO.fit denemesinde `hyso/models/bcam.py:179-180` scheduler state'ini
plan config'e taşır; JSON normalizasyonu (`:204`) şu hatayı verir:

`checkpoint training plan requires plain finite configuration values`

Bu deneyler kurulu temiz HYSo wheel'iyle yapıldı; schema veya güvenlik kontrolü
aşılmadı. Torch 2.2.2, metadata'daki torch>=2.0 aralığının içindedir. Pip check'in
geçmesi runtime uyumluluğunu kanıtlamaz. Bu, yalnız varsayımsal minimum riski değildir.

[Torch v2.0.0 resmî scheduler kaynağında](https://github.com/pytorch/pytorch/blob/v2.0.0/torch/optim/lr_scheduler.py)
da base state_dict optimizer dışındaki __dict__ alanlarını alır (satır 93),
OneCycle anneal_func atar (1647/1649). Bu kaynak bulgusu aynı temsil sorununu
minimumda da işaret eder; **Torch 2.0 runtime testi yerine geçirilmez**.

Önerilen takip: bilinen OneCycle annealing stratejisini plain metadata olarak
tanımlayan, güvenli load/plan doğrulamasını koruyan dar bir compatibility adapter
ve gerçek eski Torch regression testi; alternatif destek politikası kararı ancak
kullanıcı onayı ve kanıtla. Fonksiyonu pickle etmek, unsafe fallback kullanmak
veya scheduler state'ini sessizce atlamak çözüm sayılmamalı. Bu görevde düzeltme yok.

## 4. Resolver ve cache kanıtı

Mevcut pip HTTP cache'inden uyumlu wheel'ler incelendi. Torch 2.0.x yoktu;
Torch 2.2.2 + torchvision 0.17.2 + NumPy 1.26.4 seçildi. **32 üçüncü taraf
wheel'in tüm SHA-256'ları resmî PyPI release JSON kayıtlarıyla eşleşti**.
Toplam 305,117,327 bayt önceden mevcut dağıtım offline kullanıldı; wheelhouse'a
hardlink ile alındı. İnternetten yalnız küçük resmî metadata/kaynak metinleri okundu;
dağıtım/driver indirilmedi.

Geçici constraints: torch==2.2.2, torchvision==0.17.2, numpy==1.26.4.
Bunlar yalnız maliyet/uyum kontrollü probe profilidir; proje metadata'sı veya
genel support politikası değildir. Sınırsız güncel PyPI resolver davranışı sınanmadı.
Temiz venv'de `pip --isolated --no-cache-dir install --dry-run --no-index
--find-links <wheelhouse> -c constraints.txt --report ... <hyso-wheel>` exit=0;
33 dağıtım planladı. Gerçek kurulum aşağıda ayrıca doğrulandı.

## 5. Gerçek clean install

Canonical root'un geçici kopyasından wheel/sdist üretildi; aynı güncel wheel
yeni venv'e **dependencies etkin**, `--no-index --find-links ... -c ...` ile kuruldu.
**--no-deps veya system-site-packages kullanılmadı.** pyvenv.cfg false;
başlangıç dağıtımları yalnız pip/setuptools. Venv stdlib/interpreter tabanını
Conda'dan alır; hazır üçüncü taraf paketlerini paylaşmaz.

Gerçek install exit=0: **HYSo + 32 bağımlılık**, `pip check`:
**No broken requirements found.** Repo dışı cwd ve `python -I -B` ile HYSo dahil
bütün görülen dağıtımların locate_file kökleri venv altında doğrulandı.
Torch/torchvision/NumPy/matplotlib/seaborn/sklearn/tqdm/torchsummary/PIL import
dosyaları da aynı venv'den; kaynak checkout'tan veya global site-packages'tan değil.
Torch runtime +cpu, torch.version.cuda=None; CUDA initialized=False.

Gerçek clean runtime'da StepLR full-state ve EBO resume tamamlandı:
iki epoch orijinal plan, ilk epoch kaydından sonra üçüncü optimizer denemesinde
gerçek pre-step hook ile kontrollü kesinti, seed=999 yeni modelle ikinci epoch.
Model/buffer/optimizer/scheduler/scaler/EMA/history ve Python/NumPy/Torch RNG dahil
tam payload birebir eşit. Bu, OneCycle başarısızlığını kapatmaz.

Kurulumdan sonra yalnız özet JSON okuyucusu Windows cp1254 nedeniyle hata verdi;
mevcut rapor UTF-8 okunarak doğrulandı. **Kurulum tekrarlanmadı**; install ve
pip check logları exit=0, runtime OneCycle hatası bundan bağımsızdır.
