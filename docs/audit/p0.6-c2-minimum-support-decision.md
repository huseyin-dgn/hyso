## 6. Dependency, ABI ve resolver değerlendirmesi

- **Python 3.8/NumPy:** [NumPy 1.24.4](https://pypi.org/pypi/numpy/1.24.4/json)
  Python>=3.8 ve cp38 Windows wheel sunuyor;
  [resmî release notları](https://numpy.org/devdocs/release/1.24.4-notes.html)
  Python 3.8–3.11 desteğini belirtiyor.
  [NumPy 1.26.4](https://pypi.org/pypi/numpy/1.26.4/json) ve
  [2.0.0](https://pypi.org/pypi/numpy/2.0.0/json) Python>=3.9 ister.
  Dolayısıyla Python 3.8 aday profilinde 1.24.4 kullanılmalı; mevcut 1.26.4 clean
  profilini doğrudan oraya taşımak mümkün değil. Bu bir resolver/runtime sonucu değildir.
- **Eski Torch/NumPy 2:** vision metadata'sındaki sınırsız numpy gereksinimi,
  Python>=3.9 ortamında NumPy 2'yi dışlamaz. NumPy 1.x'e karşı derlenmiş uzantılar
  NumPy 2 ile ABI sorunu yaşayabilir; [resmî NumPy açıklaması](https://numpy.org/doc/2.0/user/troubleshooting-importerror.html)
  bu durumda numpy<2 profilini önerir. Torch 2.0 + NumPy 2 burada çalıştırılmadı;
  bu kombinasyon için yeni doğrulanmış HYSo FAIL iddiası yok. Python 3.8'de pip'in
  Requires-Python filtresi NumPy 2.0'ı zaten eler; sorun daha yeni Python'da da sürer.
- **Önerilen eski Torch profili:** Torch 2.2.2/vision 0.17.2 ile NumPy==1.26.4
  exact constraints kullanılsın; NumPy<2 bu profilin muhafazakâr ABI sınırıdır.
  Bu aralıktaki her NumPy sürümü test edilmiş sayılmaz. C1 referansında Torch
  2.5.1/vision 0.20.1/NumPy 2.2.2 kanıtı bulunduğundan bütün HYSo kullanıcıları için
  koşulsuz numpy<2 gereği bu çalışmadan çıkarılamaz. Dependency marker'ı kurulu
  Torch sürümüne göre dallanamaz; sürüm eşleşmeleri constraints/CI profilleriyle yönetilmeli.
- **torchvision:** [0.14.1 metadata'sı](https://pypi.org/pypi/torchvision/0.14.1/json)
  torch==1.13.1 ister ve HYSo torch>=2.0 ile birlikte çözülemez. Mevcut >=0.14
  ifadesi 0.14.x runtime desteği anlamına gelmez. Resmî eşler 2.0.0/0.15.1,
  2.0.1/0.15.2, 2.2.2/0.17.2 ve referans 2.5.1/0.20.1'dir; CPU/CUDA binary
  kanalı da uyumlu seçilmeli.
- **torchsummary:** bcam.py import sırasında `from torchsummary import summary`
  kullanır; mevcut runtime bağımlılığı korunmalı. [1.5.1 metadata'sı](https://pypi.org/pypi/torchsummary/1.5.1/json)
  Python sürüm sınırı bildirmez, py3-none-any wheel sunar. Bu tek başına bütün
  Python/Torch sürümleriyle uyum kanıtı değildir; bu görevde gerçek import/fit geçti.
- **Pip:** [resolver](https://pip.pypa.io/en/stable/topics/dependency-resolution/)
  Requires-Python ve dependency pinlerini değerlendirir, uyumsuz vision/Torch
  adaylarından geri dönebilir; C++/NumPy ABI'sini veya HYSo checkpoint şemasını
  çalıştırarak denetlemez. Alt sınırlar minimum sürümü seçmeye zorlamaz; açık uçlu
  aralıklar yeni ve test edilmemiş sürümler seçebilir. Bu görevde yeni büyük resolver
  çalıştırılmadı; Python 3.8 transitif graph veya unconstrained online install PASS değildir.

Matplotlib/seaborn/scikit-learn/tqdm ve transitif bağımlılıkların Python 3.8'de
uygun eski sürümlere çözülmesi de A seçeneğinin açık test yüküdür.

   PARTIAL, genel P0.6-C2 PARTIAL. P0.6-D destek/metadata kararı ve final artefakt
   doğrulaması tamamlanmadan release onayı çıkarma.
